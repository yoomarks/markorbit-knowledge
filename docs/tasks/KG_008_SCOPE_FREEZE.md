# KG-008 scope freeze

KG-008 is limited to Native Workspace search/navigation composition over capabilities that already exist in Knowledge.

Included: metadata matching, `SQLITE_FTS5_BM25` full-text retrieval, deterministic deduplication/composition, Reader navigation, bounded objective local graph navigation.

Excluded: vector search, embeddings, entity resolution, business/case relevance, truth/trust/authority ranking, legal conclusions, recommendations, strategy and any graph-derived ranking signal.
