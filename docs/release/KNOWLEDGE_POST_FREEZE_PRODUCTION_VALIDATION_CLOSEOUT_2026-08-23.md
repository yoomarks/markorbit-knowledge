Do not reopen the Source, collection authorization, RawArtifact, conversion, staging or ReadyPackage architecture merely because global source coverage remains incomplete.

The final acquisition-profile head passed Node 22/24 validation, Core Intake E2E, USPTO full-pipeline smoke, WIPO reconciliation, Country Index learning, Representative Source Live Canary and the complete IP Australia inventory, acquisition, RawArtifact, change-watch, learning and bulk-conversion workflows.

## Remaining production gates

1. Observation scope must be independent from promotion/activation scope. Adding an authority to diagnostics must not widen production promotion consumers.
2. Wave 1 targets require actual governed runs and durable scorecard evidence; manifest membership is not validation.
3. Long-lived production evidence must survive beyond ephemeral CI databases and short-retention workflow artifacts.
4. Core ReadyPackage V2 production activation still requires a dedicated Core receiver; V2 must not fall back to V1.
5. Documentation and issue state must be updated at each phase closeout so historical freeze decisions are not mistaken for current completion status.

## Current work order

1. decouple observation and promotion cohorts;
2. persist auditable Wave 1 scorecard snapshots within the supported local/self-hosted boundary;
3. run the remaining Wave 1 authorities and fix only evidence-backed generic capability gaps;
4. activate and cross-repository-test the dedicated Core ReadyPackage V2 receiver;
5. perform provider breadth and UI polish only after the production gates above.

## Boundary

Knowledge owns what was observed, how it was acquired, immutable evidence, objective changes and delivery preparation. Core/Brain owns what the evidence means, legal interpretation, importance, recommendations and user value. Acquisition intelligence improves collection policy only; it does not create legal truth.
